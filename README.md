# Projeto Banco de Dados - Eventos

## Descrição do Projeto

Projeto acadêmico destinado à modelagem, implementação e gerenciamento de um banco de dados para eventos.

## Objetivo

Desenvolver uma estrutura de banco de dados organizada, utilizando conceitos de modelagem, SQL e gerenciamento de dados.

## Estrutura do Repositório

### 01_modelagem
Documentação e diagramas do banco de dados.

### 02_scripts
Scripts SQL utilizados no projeto:

- 01_ddl_estrutura.sql — Criação da estrutura do banco.
- 02_dml_carga.sql — Inserção de dados.
- 03_objetos_prog.sql — Procedures, Functions e Triggers.
- 04_dql_consultas.sql — Consultas SQL.
- 05_dtl_testes.sql — Testes e validações.

### 03_evidencias
Evidências do desenvolvimento, testes e demonstração do projeto.

## Tecnologias Utilizadas

- MySQL
